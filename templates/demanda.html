¿Cómo funcionan los modelos?

El aprendizaje supervisado aprende relaciones entre características conocidas y resultados históricos. La clasificación estima una etiqueta BAJA, MEDIA o ALTA. La regresión estima una cantidad no negativa de atenciones.

Random Forest
Combina muchos árboles y agrega sus votos o estimaciones para reducir variaciones.
Decision Tree
Divide los datos mediante reglas sobre características. Es sencillo, pero puede ajustarse demasiado al historial.
Gradient Boosting
Construye árboles sucesivos que corrigen errores de los anteriores.
KNN
Busca días cercanos en las características escaladas y combina sus resultados. Cercanía de calendario no garantiza demanda similar.
Logistic Regression
Combina características para estimar probabilidades de las clases. El nombre no implica que prediga cantidades.
Ridge Regression
Estima cantidades con una relación lineal y penalización de coeficientes para limitar el sobreajuste.

Selección: tres ventanas cronológicas expansivas dentro del 80 % inicial. Gana el mayor F1 macro (desempate por accuracy y recall) o el menor MAE (desempate por RMSE). El escalado se ajusta sólo con cada entrenamiento. No se usan resultados futuros ni cantidades del día objetivo como entradas.

Accuracy
Fracción de etiquetas correctas.
Precision y recall macro
Promedios por clase de la precisión de las alertas y de la proporción de casos detectados.
F1 macro
Promedio del equilibrio entre precision y recall para cada clase, con igual peso para las tres etiquetas.
MAE / RMSE
Error en atenciones; RMSE penaliza más los errores grandes. Menor es mejor.
R²
Comparación del error con la variabilidad real; puede ser negativo. No se informa con variación insuficiente.

Las referencias predicen la clase más frecuente o la media del entrenamiento. Una mejora orientativa exige superar la referencia por más de 0,02 F1 o reducir MAE más del 5 % en validación y prueba. Esto no demuestra significación estadística ni fiabilidad operativa.
